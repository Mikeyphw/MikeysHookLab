**Trust boundary:** one-tap mode is explicitly optional. Android authenticates the caller's exact package and installed signer, not the provenance of a tap within that process; the user must trust the entire pinned signed ChatGPT process including hooks. Review remains the default. Fresh request IDs prevent replay; they do not prove a gesture. No auto-grant, no auto-execution after grant, no retry on ambiguous dispatch. No root, clipboard, payload log or saved code. The bootstrap writes only fixed startup scripts to a mode-0700 temporary directory and removes those on normal initialization. The command runs in a child subshell so `exit` cannot close the parent prompt; payload changes to working directory or shell variables are intentionally isolated. User startup files are trusted; unusual global startup configuration overriding ZDOTDIR or disabling RCS can prevent execution and is not silently bypassed. Session exit and command exit are distinct. Missing Zsh is refused explicitly. Termux owns terminal creation and foreground selection; no additional Android permissions are added.

Device acceptance: exact APKM/host signer and signed HookLab build; enable opt-in and save defaults once; verify tap icon dispatches exactly once, native Copy unchanged and no review; revoke opt-in restores review; permission denial and unavailable service refuse without callback dispatch; run multiline, quotes/comma/Unicode, alias/function and `exit 7`; NOART=1 before real startup, one .zshrc, preserved prompt and exit status, continue commands, check new session selected and numeric callback when closed; unsupported host/refused/replayed requests no execution; repeat scroll/rotation/lazy slot reuse and duplicate-click tests.
