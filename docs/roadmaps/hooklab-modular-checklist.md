# HookLab — Modular implementation and acceptance checklist

**Program:** HOOKLAB-MODULAR-PRIVATE · **Revision:** 1.0-proposed · **Snapshot:** 2026-11-25 (America/Sao_Paulo)

**Status:** Planning document; not an adopted roadmap, source patch, operator, device acceptance or release authorization.

This checklist covers all **50 new promises**. Every row is a planned test and integration target, not executed evidence. Default per-promise implementation `UNINSPECTED` (new work not audited against production), evidence `NOT_RUN`, acceptance `PENDING`. An unchecked box never proves absence of existing code. Promote only with concrete source call chain, exact observed results and receipt. Distinguish local/hosted/device tests and source-complete/merged/accepted. No blanket acceptance on build success.

## Per-promise checklist

### MOD-01 — Modular Core & Internal SDK

- [ ] **MOD-01-P01 — Stable module and hook identity.** Planned production path: Catalog and SDK → manifest-backed module/hook descriptors; preserve all existing hook IDs and persisted opt-ins. Required proof: Enumerate real catalog, one-to-many targets, duplicate IDs, existing preferences, missing metadata. Evidence: NOT_RUN.
- [ ] **MOD-01-P02 — Shared registry authority.** Planned production path: Manager and host use the same immutable generation; metadata available without executing module code; replace hardcoded dispatch eligibility. Required proof: Catalog/host parity, concurrent refresh, missing/stale registry and duplicate rejection. Evidence: NOT_RUN.
- [ ] **MOD-01-P03 — Versioned internal SDK.** Planned production path: Separate Java SDK and runtime Gradle modules; define binary compatibility, entrypoint, hook context, settings, diagnostics and lifecycle. Required proof: Compile built-in and independent fixture against SDK; reject incompatible API and namespace collision. Evidence: NOT_RUN.
- [ ] **MOD-01-P04 — Preserve built-in behavior.** Planned production path: Adapters for existing eligible integrations; independent hook activation, scope, safety locks and host version guards remain authoritative. Required proof: Actual caller coverage, multi-hook same-app and multi-app groups, restart and opt-in migration. Evidence: NOT_RUN.
- [ ] **MOD-01-P05 — Process eligibility.** Planned production path: Filter package/process/version and opt-in before loading any executable payload; default main-process-only. Required proof: Unsupported version, unrelated package, absent scope, denied/unavailable preference, no code loading. Evidence: NOT_RUN.
- [ ] **MOD-01-P06 — Manager/runtime boundary.** Planned production path: Manager owns writes and network; hosts consume immutable read-only metadata/settings and verified runtime content. Required proof: Disconnected framework, stale generation, no host-side network or credential exposure. Evidence: NOT_RUN.
- [ ] **MOD-01-P07 — Contract and Go foundations.** Planned production path: Versioned manifest/settings/index/receipt schemas, shared valid/invalid vectors; Go CLI skeleton and Java readers agree. Required proof: Cross-language fixtures, duplicate JSON keys, schema version, Unicode and numeric limits. Evidence: NOT_RUN.
- [ ] **MOD-01-P08 — Real device feasibility gate.** Planned production path: Tiny self-authored benign test module via supported API 102 remote file transport; inspect actual installed Vector/LSPosed version and service capabilities. Required proof: Physical device import, scope, host restart, verified hook runs only on opted-in test target; no broad file permissions; failure blocks MOD-02 runtime choice. Evidence: NOT_RUN.
- [ ] **MOD-01-P09 — SDK/lifecycle governance.** Planned production path: One cumulative devop-hooklab registry, exact source evidence, no duplicate old paths except proven external compatibility. Required proof: Native plan check, source-bound hosted tests, CI24 and baseline regression; no fake dynamic UI. Evidence: NOT_RUN.

### MOD-02 — Hook Pack Runtime & Migration

- [ ] **MOD-02-P01 — Deterministic signed pack format.** Planned production path: Go packager → canonical manifest, exact payload SHA-256 map, signature envelope; Java independent verifier. Required proof: Golden vectors, repeat byte-identical build for same inputs, tamper every member, unknown key/schema rejection. Evidence: NOT_RUN.
- [ ] **MOD-02-P02 — Safe local import.** Planned production path: SAF and Share → bounded staged archive validation; no extraction escape, executable from Downloads, symlink or duplicate entries. Required proof: Corrupt/truncated pack, traversal, ZIP bomb, oversized DEX, duplicate filenames, cancel and storage denial. Evidence: NOT_RUN.
- [ ] **MOD-02-P03 — Trusted signing identity.** Planned production path: One personal module publisher trust root, separate from existing APK signer; test key isolated, rotation/revocation explicit. Required proof: Wrong signature, unknown key, revoked key, older metadata and no signing secret on device. Evidence: NOT_RUN.
- [ ] **MOD-02-P04 — Atomic install/update registry.** Planned production path: Private staging → verified immutable payload → generation activation; journal and crash recovery, retained prior version. Required proof: Kill at each transition, disk full, simultaneous operation, failed verification, reboot and idempotent recovery. Evidence: NOT_RUN.
- [ ] **MOD-02-P05 — Host transport and loader.** Planned production path: API 102 verified remote files → bounded verified in-memory DEX or proven read-only alternative; SDK parent identity and target classloader kept distinct. Required proof: Real LSPosed scoped device loading, byte hash, unavailable file, Android 14+ restrictions, dependency/class identity errors. Evidence: NOT_RUN.
- [ ] **MOD-02-P06 — Controlled hook activation.** Planned production path: Default-off imported hooks; explicit scope and per-hook settings; no activation while registry or signature state unknown. Required proof: Install alone does not activate, denied scope, disabled hook, unsupported host, no app launch side effects. Evidence: NOT_RUN.
- [ ] **MOD-02-P07 — Failure isolation and recovery.** Planned production path: Track install handles, rollback partial registration when supported, quarantine on known exceptions, safe mode and retained known-good generation. Required proof: Throw before/after hook registration, subsequent module unaffected where possible, native crash cannot be promised isolated; independent disable/restart path. Evidence: NOT_RUN.
- [ ] **MOD-02-P08 — Removal and restart semantics.** Planned production path: Disable/remove registry generation, revoke future eligibility, preserve settings optionally; explicitly report restart needed. Required proof: Target running during removal/update, restart selects exact generation, interrupted cleanup and no false hot unload. Evidence: NOT_RUN.
- [ ] **MOD-02-P09 — Migrate current eligible hooks.** Planned production path: Package ObtainX, Word Master and eligible ChatGPT hooks without changing existing behavior; MCC manager-sensitive workflow stays built in until separately verified. Required proof: Exact existing IDs and configuration, prior hook behavior, no duplicate registrations, no migration of retired hooks. Evidence: NOT_RUN.
- [ ] **MOD-02-P10 — Package validation tooling.** Planned production path: Go hooklabctl pack/verify/inspect uses independent validation; Gradle/D8 build in hosted CI only. Required proof: Go unit/fuzz and Java parity, malformed inputs and exact artifact validation; hosted signed pack smoke. Evidence: NOT_RUN.
