- `lxl.a` `CodeBlockImpl` is a `public static final void` method with 20 parameters: `(String, String, xpm0, r0o0, r0o0, float, boolean, boolean, boolean, boolean, Function0, Function2, boolean, boolean, Function0, boolean, va41, rqr, int, int)`.
- The two candidate `Function0` callbacks remain in renderer parameter positions **10 and 14** (zero-based). Neither is assumed to be Copy from the static method descriptor.
- `lxl.c` `CopyButtonImpl` is a `public static final void` method with `(int, int, co3, rqr, r0o0)` parameters. That function is a Compose *renderer*, not a tap or callback handler.
- The independent `scripts/check_cgt01_p04_apkm.py` parser validates package/version metadata, SHA-256 of base.apk/classes4.dex, exact descriptor/static flags, and method-local const-string marker references. It does not decompile or execute the APK, and it rejects other variants before accepting symbols.

## Production implementation

- Existing `chatgpt.codeblock.copy.probe` tweak ID is retained. HookLab is still default-off, framework-scope opt-in and version-name/code pinned. The previous 1.2026.314 hook is deliberately retired; 1.2026.321 is the only supported code for this updated probe.
- The existing `CodeBlockProbeMatcher` HMAC/byte-count value-only correlation, and `CodeBlockActionMatcher` callback-identity correlation, are unchanged.
- The new `lxl.c` hook calls the host first and logs a one-time `CGT01_COPY_BUTTON_RENDER_OBSERVED` **only as rendering evidence**. `lxl.a` analogously logs one-time `CGT01_NATIVE_RENDER_OBSERVED`, then preserves exact source-string HMAC observation and callback roles 10/14.
- Existing `ClipboardManager.setPrimaryClip` observation remains after the host call and does not read old clipboard contents. Logs contain *no raw code, code hashes without process-local HMAC keys, conversation identifiers, or sensitive paths*. The module does not add permissions, Termux dispatch, shell execution, network operations or persistent storage.
- This overlay **does not add a visible Termux button**. Button injection requires independently verified tap-to-selected-block identity and a user-approved Termux handoff security design. It is never inferred from CopyButtonImpl render or equal clipboard text.
